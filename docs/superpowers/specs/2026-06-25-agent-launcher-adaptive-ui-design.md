# Agent Launcher 自适应双模式重构设计

日期：2026-06-25  
目标分支：`feat/session-monitor-panel-redesign`

## 1. 背景

当前 Agent Launcher 主窗口把目录选择、Terminal 外观、Claude/Hermes 启动按钮和状态提示集中在 `terminal_manager_core.py` 的单个 UI 构建流程中。随着 Session Monitor、终端聚焦、外观预览和启动选项持续增加，继续在核心文件内扩展会进一步放大职责混杂、测试困难和补丁顺序脆弱的问题。

本轮采用模块化重构，保留现有 Session Monitor、托盘和终端聚焦能力，重做 Launcher 主窗口的信息架构、交互和数据层。

## 2. 目标

1. 默认提供紧凑、快速、低干扰的启动器。
2. 在同一窗口内平滑展开为完整控制台。
3. 支持收藏、最近目录、后台目录索引和快速搜索。
4. 支持 Claude/Hermes 启动选项。
5. 支持 Terminal 外观实时预览、应用和回滚。
6. 将 UI、状态、索引、动画、外观和启动逻辑拆分为独立模块。
7. 不破坏现有 Session Monitor、托盘和终端窗口映射逻辑。

## 3. 非目标

本轮不实现：

- 自定义环境变量；
- 项目级启动模板；
- 全盘搜索；
- 文件系统实时监听；
- 定时自动索引；
- 多 Agent 并行启动；
- Session Monitor 重构；
- Terminal 聚焦模块的全面重写。

## 4. 已确认的产品决策

- 使用“紧凑模式 + 展开模式”的同窗口双模式设计。
- 展开时固定窗口左上角，向右和向下增长。
- 展开/收起动画约 220 ms。
- 每次启动始终进入紧凑模式，但恢复上次窗口位置。
- 紧凑模式显示收藏、最近使用和搜索结果，不显示完整目录树。
- 单击目录仅选择；双击启动 Claude；`Enter` 启动 Claude；`Ctrl+Enter` 启动 Hermes。
- 最近使用持久化，最多 8 个；收藏持久化且数量不限。
- 收藏通过目录行右侧常驻星标操作。
- 搜索范围为已配置根目录及其子目录。
- 启动时后台建立内存索引，并支持手动刷新。
- 默认忽略 `.git`、`node_modules`、`.venv`、`venv`、`__pycache__`、`dist`、`build`、`.idea`、`.vscode`。
- 展开模式右侧显示当前项目、启动选项和 Terminal 外观。
- 首版启动选项：新窗口/新标签页、跳过权限确认、启动后隐藏 Launcher。
- Terminal 外观采用实时预览，点击“应用”后持久化；取消、收起或关闭时回滚未应用修改。

## 5. 总体架构

### 5.1 `launcher_view.py`

只负责界面和用户输入，不直接扫描磁盘、写配置或启动进程。

职责：

- 构建紧凑模式和展开模式；
- 渲染搜索框、收藏、最近目录、搜索结果；
- 渲染当前项目、启动选项和 Terminal 外观；
- 处理鼠标、键盘、焦点和列表选择；
- 发送事件给控制层；
- 显示状态和错误信息。

事件接口：

```python
on_select(path)
on_launch(agent_type)
on_toggle_favorite(path)
on_search(query)
on_refresh_index()
on_toggle_expanded()
on_apply_appearance(settings)
on_cancel_appearance()
```

### 5.2 `launcher_state.py`

统一管理 Launcher 持久化状态。

存储路径：

```text
%USERPROFILE%\.agent-launcher\launcher-state.json
```

数据结构：

```json
{
  "version": 1,
  "window": {
    "x": 120,
    "y": 80
  },
  "favorites": [],
  "recent_directories": [],
  "launch_options": {
    "terminal_mode": "window",
    "skip_permissions": false,
    "hide_after_launch": false
  },
  "appearance": {
    "mode": "none",
    "opacity": 50
  }
}
```

规则：

- 最近目录去重并限制为 8 个；
- 收藏数量不限；
- 不保存展开状态；
- 每次启动进入紧凑模式；
- 恢复并校正窗口位置，避免窗口出现在不可见显示器区域；
- 明确不存在的本地目录自动清理；
- 暂时不可访问的网络目录不立即删除；
- 使用临时文件写入后原子替换；
- 配置损坏时备份原文件并恢复默认值。

### 5.3 `directory_index.py`

负责后台目录扫描和搜索。

职责：

- 扫描所有已配置根目录及其子目录；
- 去重重叠根目录；
- 应用默认排除规则；
- 在后台线程执行，不阻塞 Tk 主线程；
- 维护只读内存快照；
- 支持手动刷新；
- 保存无法访问的目录摘要；
- 通过 `root.after(...)` 把 UI 更新切回主线程。

索引记录至少包含：

```python
DirectoryEntry(
    name: str,
    path: str,
    root_path: str,
    relative_path: str,
)
```

搜索为大小写不敏感匹配，最多返回 30 项。排序优先级：

1. 目录名完全匹配；
2. 目录名前缀匹配；
3. 目录名包含；
4. 相对路径包含；
5. 同级结果按最近使用时间排序；
6. 最后按名称稳定排序。

### 5.4 `launcher_animation.py`

负责窗口模式切换，不管理业务状态。

目标尺寸：

- 紧凑模式：约 `360 × 320`；
- 展开模式：约 `720 × 520`。

规则：

- 动画时长约 220 ms；
- 使用平滑缓动；
- 左上角坐标保持不变；
- 展开期间忽略重复切换请求；
- 根据当前显示器工作区限制目标尺寸；
- 动画被最小化、关闭或显示器变化打断时安全取消；
- 所有 `after()` 回调可追踪并在退出时注销。

### 5.5 `terminal_appearance.py`

负责 Terminal 外观事务。

职责：

- 读取最后一次已应用值；
- 在控件变化时实时预览；
- 点击“应用”后持久化；
- 点击“取消”、收起窗口或关闭 Launcher 时回滚；
- 继续支持 Acrylic、Opacity 和 Solid 三种模式；
- 保持现有 Windows Terminal 配置修改方式兼容。

状态模型：

```python
applied_settings
preview_settings
is_dirty
```

只有 `apply()` 能更新 `applied_settings` 和持久化状态。

### 5.6 `launch_controller.py`

负责启动流程和启动选项。

职责：

- 校验当前选中目录；
- 构造 Claude/Hermes 启动请求；
- 应用新窗口/新标签页选项；
- 应用跳过权限确认选项；
- 调用现有 Terminal 启动和 HWND 注册逻辑；
- 启动成功后更新最近目录；
- 根据设置隐藏 Launcher；
- 启动失败时不更新最近目录、不隐藏窗口；
- 输出结构化诊断日志。

“新窗口”是默认模式，也是唯一保证 Session Monitor 卡片精确对应独立 Terminal 窗口的模式。

“新标签页”首版使用最近活动的 Windows Terminal 窗口创建标签页。由于多个标签共享同一 HWND，且 Windows Terminal 仅提供按标签索引聚焦，用户关闭或重排标签后索引可能变化，因此首版只保证聚焦到包含该会话的 Terminal 窗口，不承诺长期精确切换到对应标签。界面应在“新标签页”旁显示简短提示。该限制必须显式记录，不得伪装成精确会话路由。

### 5.7 `terminal_manager_core.py`

重构后只负责组合和生命周期：

```text
初始化根窗口
  → 加载 LauncherState
  → 创建 DirectoryIndex
  → 创建 LaunchController
  → 创建 TerminalAppearanceController
  → 创建 LauncherView
  → 启动后台索引
  → 启动 Session Monitor
  → 启动托盘
```

旧的 Launcher `build_ui()`、目录列表管理、背景控件和 Launcher 事件处理迁出核心。Session Monitor、托盘和终端聚焦仅做必要接口适配，不在本轮重写。

## 6. 界面设计

### 6.1 紧凑模式

```text
┌──────────────────────────────────────┐
│ Agent Launcher            [刷新] [展开] │
│ [ 搜索项目或目录…                 ]  │
├──────────────────────────────────────┤
│ 收藏                                 │
│ ★ WorldQuant Brain                  │
│ ★ terminal-manager                  │
│                                      │
│ 最近使用                             │
│ ☆ Kaggle                            │
│ ☆ ECO3121                           │
├──────────────────────────────────────┤
│ 当前：D:\...\WorldQuant Brain       │
│ [ Claude Code ]      [ Hermes ]      │
│ 状态信息                             │
└──────────────────────────────────────┘
```

行为：

- 搜索为空时显示收藏和最近使用；
- 输入搜索词后仅显示搜索结果；
- 单击主体选择目录；
- 双击主体启动 Claude；
- 单击星标切换收藏，不改变当前选择；
- `↑/↓` 移动选择；
- `Enter` 启动 Claude；
- `Ctrl+Enter` 启动 Hermes；
- 收藏和最近目录中的重复路径只显示一次，收藏优先。

### 6.2 展开模式

```text
┌─────────────────────────────────────────────────────────────┐
│ Agent Launcher                         [刷新索引] [收起]     │
├────────────────────────────┬────────────────────────────────┤
│ 搜索框                     │ 当前项目                       │
│ 收藏                       │ 名称和完整路径                 │
│ 最近使用                   │ [打开资源管理器] [复制路径]    │
│ 搜索结果                   │                                │
│                            │ 启动                           │
│                            │ [Claude Code] [Hermes]         │
│                            │ ○ 新窗口  ○ 新标签页           │
│                            │ □ 跳过权限确认                 │
│                            │ □ 启动后隐藏 Launcher          │
│                            │                                │
│                            │ Terminal 外观                  │
│                            │ Acrylic / Opacity / Solid      │
│                            │ 透明度 ───────── 50%           │
│                            │ [取消预览] [应用]              │
└────────────────────────────┴────────────────────────────────┘
```

展开后保持：

- 搜索内容；
- 当前选择；
- 列表滚动位置；
- 收藏和最近数据；
- 当前预览状态。

收起时若外观存在未应用修改，先回滚，再执行收起动画。

## 7. 状态反馈

底部使用单行状态区域，避免无必要弹窗。

常见消息：

- `正在建立目录索引…`
- `已索引 428 个目录`
- `部分目录无法访问`
- `正在启动 Claude…`
- `已启动 WorldQuant Brain`
- `Terminal 外观已应用`
- `启动失败：未找到 wt.exe`

普通成功信息短暂显示；错误信息保留到下一次操作或用户明确关闭。

## 8. 数据流

### 搜索

```text
用户输入
  → LauncherView
  → DirectoryIndex.search()
  → 排序后的快照
  → LauncherView 渲染
```

### 启动

```text
用户启动 Claude/Hermes
  → LaunchController 校验目录
  → 构造启动参数
  → 调用现有 Terminal 启动器
  → 注册窗口映射
  → 更新最近目录
  → 可选隐藏 Launcher
```

### 外观预览

```text
控件变化
  → preview(settings)
  → 实时修改 Terminal 外观
  → apply() 持久化
  或 cancel()/collapse()/close() 回滚
```

## 9. 容错

### 配置损坏

- 将损坏文件重命名为带时间戳的备份；
- 使用默认状态继续启动；
- 状态栏提示配置已重置；
- 不阻止主窗口显示。

### 索引失败

- 单个目录失败不终止全局扫描；
- 跳过失败目录并记录摘要；
- 手动刷新时重新尝试；
- 后台线程不得直接更新 Tk 控件。

### 启动失败

- 不更新最近目录；
- 不隐藏 Launcher；
- 显示可操作错误；
- 日志记录 Agent 类型、目标目录和异常摘要；
- 不记录敏感环境变量。

### 动画异常

- 取消剩余回调；
- 保留最近有效尺寸；
- 不改变窗口左上角；
- 退出时清理所有动画回调。

## 10. 诊断日志

日志路径：

```text
%USERPROFILE%\.agent-launcher\agent-launcher.log
```

采用轮转日志：

- 单文件上限约 1 MB；
- 保留最近 3 个文件；
- 记录配置加载、索引、启动请求、外观应用、动画异常和 Terminal 映射摘要；
- 正常操作只记录摘要；
- 不记录完整环境变量、令牌或敏感命令内容。

## 11. 兼容与迁移

- 继续读取现有目录配置来源；
- 首次启动时从现有 Terminal 设置读取已应用外观；
- 现有 Session Monitor 配置和终端映射文件保持不变；
- 新的 `launcher-state.json` 只保存 Launcher 状态；
- 原 `terminal_manager_core.py` 中 Launcher 相关逻辑迁移完成后删除，避免双实现；
- 不增加新的运行时第三方依赖。

## 13. 完成标准

本设计完成需同时满足：

- Launcher 主窗口默认紧凑、可在同一窗口平滑展开；
- 新模块边界清晰，核心文件不再承载 Launcher 业务实现；
- 搜索、收藏、最近目录和手动刷新可用；
- 启动选项可持久化；
- Terminal 外观支持预览、应用和回滚；
- 新窗口模式不破坏现有精确终端映射；
- 配置、索引、启动和动画异常不会阻止应用启动或安全退出；
- 单元测试和集成测试覆盖上述关键路径；
- Windows 手工验收完成后才可声明功能完成。
